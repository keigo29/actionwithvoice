# フォントを置く場所

Ray の画面は、英数字と記号に CP Mono（CPMono_v07）をいちばん優先して使います。日本語の文字は Zen Kaku Gothic New です。

- Mac に CP Mono を入れていれば、それを使います（`CPMono_v07 Plain` などの名前で探します）
- 入れていないときは、ここに `CPMono_v07_Plain.otf`・`CPMono_v07_Light.otf`・`CPMono_v07_Bold.otf`・`CPMono_v07_Black.otf` を置くと、それを使います
- フォントのファイルは Git には入れません
